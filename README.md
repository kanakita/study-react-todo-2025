# TODO アプリを作成する

## 機能要件
- [x] ブラウザで動く
- [x] データは、localStorageに保存
- [x] TODOの追加、削除ができる
- [ ] TODOの編集ができる
- [x] TODOは完了/未完了の状態を持つ
- [x] TODOのフィルタリングができる (未完了/完了)
- [x] TODO には優先度が設定可能。(高/中/低)
- [x] TODOの並び替えができる (作成日/優先度)
